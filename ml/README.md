# ML (Machine Learning) module — future work only

**No machine learning is implemented in this repository.** This folder is reserved for possible future work only.

- **Current state:** No ML components are used anywhere in the pipeline. No trained models, no inference code, no neural networks.

- **Future work:** If ML-based refinement is ever added, it would be placed here and documented as such. Do not claim ML is implemented unless such code exists.
